# PocketFiles demo snapshot

This folder contains an earlier standalone PocketFiles demo (version `0.1.0`). It is kept as a reference build and is separate from the current extension in the project root.

For the current release, load the **top-level project folder** — the folder containing the root `manifest.json` — and follow the main [README](../README.md) and [setup guide](../guide.md).

This older demo does not include the current Native Messaging permission or Desktop Bridge integration. Its behavior and limits may differ from the current release.
