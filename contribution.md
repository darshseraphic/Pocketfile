# Contributing

Thank you for taking the time to review PocketFiles and share feedback.

## Before contributing

PocketFiles is governed by the proprietary source-available terms in [`LICENSE.txt`](LICENSE.txt). Public source visibility allows inspection and evaluation; it does not grant general rights to modify the project, publish forks, redistribute code, or use it commercially.

You may report bugs, suggest improvements, and test official unmodified releases within the license terms. Do not submit code changes, patches, or modified copies unless you have first received explicit written permission from the copyright holder.

## Report an issue

Please include:

- PocketFiles version (see `manifest.json`).
- Browser and operating system versions.
- Steps to reproduce the issue.
- Expected and actual behavior.
- Relevant error messages, and whether the Desktop Bridge is installed.

Screenshots or short recordings are helpful when relevant. Remove private file names, paths, file contents, and other personal information before sharing logs or images.

## Suggest an improvement

Describe the problem you are trying to solve and the behavior you would expect. Include examples or screenshots where they clarify the suggestion.
