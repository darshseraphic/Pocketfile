03 / Local by design

Your files stay
on your device.

PocketFiles works with folders you explicitly connect. File browsing and processing happen locally in the extension, not through a PocketFiles upload service.

Read the security notes ↗
⌖

You choose the folder.

The browser's folder picker asks for access. PocketFiles uses the folder handle you grant and stores it in IndexedDB.

⌁

No website host permissions.

The extension declares storage, sidePanel, and nativeMessaging permissions. It does not request access to the websites you visit.

▣

Local file processing.

Favorites, recent items, and preferences use extension-local storage. File operations are handled on your device.

⇧

Bridge when you need it.

The optional Desktop Bridge communicates through Native Messaging and does not use the network.

05 / Useful details

A little more
to know.

Some details before you connect a folder.

Which browsers does PocketFiles support?

PocketFiles is a Manifest V3 extension for desktop Chromium browsers. The supplied manifest specifies Chrome 116 or later. The project guide also includes setup notes for Chrome and Edge.

Does PocketFiles upload or sync my files?

The current project processes files locally and does not use a PocketFiles cloud service. Access is limited to folders you choose through the browser's folder picker. Review the security notes for the full data-handling description.

Do I need the Desktop Bridge?

No. The bridge is only needed for the native operating-system file clipboard Copy action. Folder browsing, previews, Save, ZIP creation, and ZIP extraction work without it.

Which files can I preview?

PocketFiles can preview images, PDFs, and common text-based files. Text-based previews are limited to 2 MB. Other file types can still be saved or dragged to supported destinations.

What ZIP formats are supported?

The built-in ZIP reader supports Store and Deflate entries. Encrypted archives and ZIP64 are not supported.

Does native Copy move or change my original files?

No. The Desktop Bridge stages temporary copies in the operating system's PocketFilesClipboard temp folder and places those paths on the native file clipboard. It does not move or modify the originals.
