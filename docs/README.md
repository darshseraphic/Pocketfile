# PocketFiles Website

A responsive static website for the PocketFiles browser extension. The layout and visual direction are based on the supplied Climano website reference, adapted to PocketFiles' actual feature set and local-first workflow.

## Files

- `index.html` — landing page content and interface preview.
- `styles.css` — responsive layout, light/dark themes, and component styling.
- `script.js` — theme control, mobile navigation, copyable Git command, and footer year.
- `assets/` — PocketFiles logo and extension icon.

## Preview locally

Open `index.html` in a browser. No build tools, frameworks, external fonts, or runtime services are required.

## Publish

The folder can be served as a static website or used as the source directory for a static hosting service. Update the GitHub documentation links in `index.html` if the repository's default branch or file paths change.
