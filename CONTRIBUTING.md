## Ways to contribute

### Report a bug

When reporting a problem, include:

- A clear, short description of what happened.
- The steps needed to reproduce it.
- What you expected to happen and what happened instead.
- Your Chrome version and operating system.
- The Pocketfile version shown in the project manifest (currently `1.2.0`).
- Relevant error text from Chrome's extension inspection tools, if available.

Please remove personal information, private task titles, and other sensitive details from screenshots and logs before sharing them.

### Suggest an improvement

Describe the problem the suggestion would solve, who it affects, and the behavior you would expect. For interface suggestions, include the screen or control involved and, where useful, a sketch or screenshot with private information removed.

### Help with documentation and testing

You can point out unclear wording, missing setup steps, accessibility problems, confusing interactions, or differences between the documented behavior and the extension. Reproduction steps are especially useful for reminder timing, notification delivery, theme switching, and task editing.

## Reporting security issues

Do not report suspected vulnerabilities in a public issue. Send them privately using the process in [`security.md`](security.md).

## Communication guidelines

Please be specific, respectful, and constructive. Keep reports focused on one issue where possible, avoid including secrets or personal data, and do not post anyone else's private information.
